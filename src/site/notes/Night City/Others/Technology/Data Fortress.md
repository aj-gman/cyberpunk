A designated space in the [[Night City/Others/Technology/NET\|NET]] that exists with security around it, allowing entrance only within specific parameters. 
A [[Night City/Others/Technology/Data Fortress\|Data Fortress]] is [[Night City/Locations/Districts/City Center#Civic Center\|City Hall]], which has multiple layers that can be accessed, from the Public E-Library to the Forum to the Administrative Units (which are only available to bureaucrats).

Not to be confused with an [[Night City/Others/Technology/IntraNET\|IntraNET]], a type of [[Night City/Others/Technology/NET\|NET]] structure that functions like the [[Night City/Others/Technology/NET\|wider web]] but is centralized in a few physical servers.
