In [[Rules/CPRED/Cyberpunk RED (HUB)\|Cyberpunk RED (HUB)]], Quality is measured by the price of a given item (Price Bands). However, Weapon Quality is measured by a three-category system (Poor < Standard < Excellent). 
[[Rules/CPRED/Cyberware/Cyberware\|Rules/CPRED/Cyberware/Cyberware]] is measured from 1 to 5, starting with Costly (50eb) and ending with Luxury (5000eb).

| Price Bands        | Market Price |
| :----------------- | :----------: |
| Cheap              |     10eb     |
| Everyday           |     20eb     |
| ==Costly==         |   ==50eb==   |
| ==Premium==        |  ==100eb==   |
| ==Expensive==      |  ==500eb==   |
| ==Very Expensive== |  ==1000eb==  |
| ==Luxury==         |  ==5000eb==  |
| Super Luxury       |  10,000eb+   |
